## Reporting a Vulnerability

We take the security of MindSpark seriously. If you discover a security vulnerability, please do **NOT** open a public GitHub issue.

Instead, please send an email directly to **mindsparkelite6@gmail.com** with details of the issue.

### What to Include:
* A clear description of the vulnerability.
* Step-by-step instructions or proof-of-concept to reproduce the bug.
* The potential impact on users or the system.

We will review your report promptly, confirm the vulnerability, and release a patch as quickly as possible.
